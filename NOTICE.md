This adaptation is released under the same licence (see `LICENSE`).

Changes made: the code was rewritten for current Minecraft versions (1.21.11 and the 26.x line) and for
Fabric, NeoForge and Forge from one codegen source; the original configuration library was replaced by a
plain config file in the same `enabled: true|false` form; the mod now records the real centre and zoom of a
map (instead of the filling player's position), and still reads the data written by the original mod.

The original mod credits somyk's Map Art Copyright as the base it was built on.
