# Fill Map Coordinates

Hover a filled map and see the exact corner coordinates of the area it covers, right in the item tooltip.

## Why Fill Map Coordinates
- No more guessing where a map points: the tooltip shows the top-left and bottom-right corner, for every map you hold.
- Stays correct when you zoom a map out on a cartography table.
- Works on maps from explorer and treasure loot as well as maps you fill yourself.
- Maps made by the original Filled Map Coordinates mod still show their area.
- One setting, one command: `/mapcoordinates enabled true` or `false`.

## Usage
Install the mod on both the server and the client, then use maps the way you always do. Hover a filled map in
your inventory and the tooltip adds a line such as `Area: (-576, -1088) to (-65, -577)`. Maps that were
created before the mod was installed have no recorded area and show nothing extra.

Ships as a Fabric, NeoForge and Forge mod for Minecraft 1.21.11 and the 26.x line.
